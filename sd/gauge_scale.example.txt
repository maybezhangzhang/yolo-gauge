# Gauge calibration for the SD card.
#
# Copy this file to the card root as  gauge_scale.txt  to enable real units.
# Without it the firmware reports the needle position as a fraction of the
# detected scale arc (unit "frac"), which is honest but not an absolute value.
#
# Keys (all optional, missing keys keep the previous value, '#' starts a comment):
#   min         value printed at the scale start
#   max         value printed at the scale end
#   unit        shown on the banner, keep it ASCII and short
#   clockwise   1 = the scale runs clockwise on screen (normal), 0 = counter-clockwise
#   angle_min   direction of the minimum number, degrees from the hub (0 = +X, y down)
#   angle_max   direction of the maximum number
#
# Two worked examples (uncomment one, or write your own):

# --- example A: SWISS MOVEMENT dial, -1..3 bar (sd/test1.bmp) ---
# min       = -1
# max       = 3
# unit      = bar
# clockwise = 1
# angle_min = 136.5
# angle_max = 43.0

# --- example B: Tomsk dial, 0..16 kgf/cm2 (sd/test2.bmp) ---
# min       = 0
# max       = 16
# unit      = kgf/cm2
# clockwise = 1
# angle_min = 137.4
# angle_max = 43.7
#
# The two angles can be derived from a labelling file instead of measured by eye:
#   python tools/scale_from_labels.py <label.txt> <image-width> <image-height>
# It prints amin / amax / span / the detected tip angle and the resulting value.
